# Security

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting

DM `@theelephantcoder` on Discord or open a GitHub issue. If you open an issue, note that it's a private vuln and I'll handle it from there.

Include what it is, how bad it is, and steps to repro if you have them.

I'll try to respond within a couple days. Critical fixes usually go out within a week. Happy to credit you if you want, or keep it private.

## What counts

Prompt injection bypasses, secret leakage through memory or logs, sandbox escapes, sketchy skill supply chain stuff.

Full policy is in `security/policy.md`.
