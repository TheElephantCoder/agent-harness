Skills

Reusable SKILL.md that follows the agent skills spec. Write once, use in every harness. Pull in others like vercel-labs/agent-skills without copying.

harness skill add harness/research-first

Instincts

Hooks that fire on their own. Pre-tool guard, post-edit format + typecheck, session hydration. Muscle memory for agents.

instincts/research-first blocks edits until plan exists

Memory

Tiered MEMORY.md under 8k tokens. Hot always, warm on keyword, cold on demand. Sessions distill on exit, no 3 minute re-explanation.

memory/MEMORY.md + SOUL.md + USER.md

Security

Default deny. Prompt injection check, secret scan before commit, bash allowlist, file boundaries. Catches the dumb mistakes.

harness security audit

Research-first

Agent checks research/findings/ first, then codebase, then web. Writes research/plans/ and waits for an ok.

research → plan → approve → build

Quick start

npm install -g @theelephantcoder/agent-harness
npx @theelephantcoder/agent-harness init --auto
harness doctor
harness bench --quick
brew tap TheElephantCoder/agent-harness
brew install agent-harness
harness doctor
pip install agent-harness-cli
pipx install agent-harness-cli
harness doctor
echo "deb [trusted=yes] https://theelephantcoder.github.io/agent-harness/apt stable main" | sudo tee /etc/apt/sources.list.d/agent-harness.list
sudo apt update
sudo apt install agent-harness
harness doctor
git clone https://github.com/TheElephantCoder/agent-harness.git
cd agent-harness
npm install
npm link

Research-first flow

  1. research — check research/findings/, grep codebase, web search if needed
  2. plan — write research/plans/<task>.md
  3. approve — quick ok (tiny edits auto-approve)
  4. build — implement
  5. verify — tests + harness bench + harness security audit
  6. remember — harness memory sync distills

Works on your existing repo

npx @theelephantcoder/agent-harness init --migrate
git status # see what it added
harness doctor --fix

Remove the harness and your project still works — adapters are just transpilers.
